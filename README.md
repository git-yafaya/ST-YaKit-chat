# 纪实

纪实是 YaKit 系列中的 SillyTavern 聊天记录导出扩展，按楼层范围和消息类型，把当前聊天导出成文本文件。当前版本还没有界面，需要在浏览器控制台里输入代码来使用。

## 功能特性

- 按楼层范围导出：可以选择全部楼层，也可以指定起止楼层；起止楼层填反了会自动交换，超出实际楼层数会自动收缩到有效范围
- 按消息类型过滤：可以只保留 AI 回复、用户台词、系统提示中的一种或几种
- 导出为文本文件：支持"带类别标注（AI：/用户：/系统：）"和"仅保留正文"两种格式，导出后浏览器会自动下载
- 只支持单人聊天，暂不支持群聊

## 安装方法

安装后，打开浏览器控制台就能把当前聊天导出成文本文件；这一步目前还没有界面，需要手动输入几行代码。

1. 打开酒馆的扩展面板，选择安装扩展
2. 粘贴以下仓库地址完成安装

   ```text
   https://github.com/git-yafaya/ST-YaKit-chat
   ```
3. 刷新酒馆
4. 打开一段想要导出的单人聊天，按 F12（或右键页面选择"检查"）打开浏览器开发者工具，切换到 Console（控制台）标签
5. 在控制台里按下方"使用说明"输入导出命令，浏览器会自动下载文件

## 使用说明

1. 在酒馆里打开一段想要导出的单人聊天（暂不支持群聊）
2. 在浏览器控制台读取想要的楼层范围，楼层从 1 开始计数，范围包含起止楼层。例如读取第 1 到第 10 楼：

   ```js
   const messages = YaKitChat.readCurrentChat({ start: 1, end: 10 });
   ```

   读取全部楼层可以写成 `YaKitChat.readCurrentChat('all')` 或不传参数 `YaKitChat.readCurrentChat()`。
3. 按消息类型过滤，例如只保留 AI 回复：

   ```js
   const selected = YaKitChat.filterMessages(messages, { ai: true });
   ```

   不传第二个参数时，默认保留 AI 回复、用户台词、系统提示三种类型；如果传了参数但三种全部关闭，会提示"请至少选择一种消息类型"。
4. 导出为文本文件，二选一：

   ```js
   await YaKitChat.saveTxt(selected, 'speaker'); // 按类别标注 AI：/用户：/系统：
   await YaKitChat.saveTxt(selected, 'plain');   // 仅保留正文
   ```

   浏览器会自动下载一个以"角色卡名称+时间"命名的 .txt 文件；如果筛选结果是空的，不会下载文件，只会提示"无内容"。

## 兼容性

已验证运行环境为 SillyTavern 1.18.0（本次开发和人工验收所用版本）。用到的读取聊天状态和触发下载这两个能力，在更早的版本里已经存在，但官方没有给出明确的最低版本承诺，所以暂时只标注"已验证版本"，还没有确切的最低版本门槛。
