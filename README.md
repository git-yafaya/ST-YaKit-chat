# 纪实

纪实是 YaKit 系列中的 SillyTavern 聊天记录导出扩展。从聊天输入框旁的扩展菜单打开面板，就能按楼层范围、消息类型和正则规则筛选当前聊天，导出成文本文件。

## 功能特性

- 按楼层范围导出：可以选择全部楼层，也可以指定起止楼层；起止楼层填反了会自动交换，超出实际楼层数会自动收缩到有效范围
- 按消息类型过滤：可以只保留 AI 回复、用户台词、系统提示中的一种或几种，三种都取消时无法导出
- 正则清洗：可以添加多条正则规则，选择"删除匹配到的内容"或"只保留匹配到的内容"；某条规则写错了只会提示该条无效，不影响其他规则和导出
- 导出为文本文件：支持"带类别标注（AI：/用户：/系统：）"和"仅保留正文"两种格式，点击导出后浏览器自动下载
- 只支持单人聊天，暂不支持群聊

## 安装方法

安装后，从扩展菜单打开面板，选好条件点一下"导出"就能拿到文件。

1. 打开酒馆的扩展面板，选择安装扩展
2. 粘贴以下仓库地址完成安装

   ```text
   https://github.com/git-yafaya/ST-YaKit-chat
   ```
3. 刷新酒馆
4. 打开一段想要导出的单人聊天，点击输入框旁扩展菜单里的"纪实"图标，打开面板

## 使用说明

1. 在酒馆里打开一段想要导出的单人聊天；如果当前是群聊，面板会提示"仅支持单人聊天"
2. 在"楼层范围"卡片里选择导出全部楼层，或者关闭这个开关后填写起始、结束楼层（填反或超出实际楼层数会自动纠正）
3. 在"消息类型"卡片里勾选要保留的类型：AI回复、用户台词、系统提示，至少勾选一种，否则"导出"按钮不可用
4. 需要清洗正文时，在"正则清洗"卡片里选择"删除匹配到的内容"或"只保留匹配到的内容"，点击"添加规则"填写正则表达式；不需要清洗就不用添加规则
5. 在底部选择导出格式（带类别标注/仅正文），点击"导出"

导出成功会有提示并自动下载一个文本文件；筛选或清洗后没有内容时会提示"无内容"，不会下载空文件。

## 兼容性

已验证运行环境为 SillyTavern 1.18.0（本次开发和人工验收所用版本）。用到的读取聊天状态和触发下载这两个能力，在更早的版本里已经存在，但官方没有给出明确的最低版本承诺，所以暂时只标注"已验证版本"，还没有确切的最低版本门槛。
