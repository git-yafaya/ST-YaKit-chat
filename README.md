# 纪实

纪实是 YaKit 系列中的 SillyTavern 聊天记录导出扩展：在面板里先预览导出效果，用正则去掉思维链、状态栏这类不想要的内容，再把当前聊天导出成 TXT、Markdown 或 EPUB 文件。

## 功能特性

- **导出预览**：面板最上方实时显示最近 2 条消息导出后的样子，改规则、改设置马上就能看到效果
- **正则匹配**：可以添加多条规则，选择「删除匹配」或「只保留匹配」；某条规则写错了只会提示「这条规则无效，已忽略」，不影响其他规则
- **识别到的标签**：自动找出最近两层楼里出现的标签（如 `<thinking>`、`<details>`、`<br/>`），点一下就加入能删掉整块内容的规则，再点一下取消，不用自己写正则；标签多时点「展开」查看全部
- **按楼层范围导出**：可以导出全部楼层，也可以指定起止楼层；填反了会自动交换，超出范围会自动收回到有效楼层
- **按消息类型导出**：AI 回复、用户台词、系统提示可以任选几种；被隐藏的楼层算作系统提示
- **三种文件格式**：TXT、Markdown、EPUB 电子书；可以选择每段前面标出是谁说的（带类别标注），或者只保留正文
- **自定义文件名**：不填时自动用角色名加日期命名
- **预设**：把导出页的规则、消息类型和格式存成一套预设，在导出页下拉框里一键切换；可以重命名、复制、删除，也能导出成文件分享给别人或导入别人的预设
- **备份**：把全部预设和纪实的设置存成一个文件，换设备或重装后一键恢复
- **八套主题**：默认「冷杉与海盐」，还可以选浅色、深色、暮色无花果、橄榄岩与日光柠檬、暖橙晨曦、咩咩（暗夜紫配赛博青），或者「跟随ST」自动沿用你当前酒馆美化的颜色和字体
- **插件更新**：在设置里检查纪实有没有新版本，一键更新，更新完自动刷新网页；只更新纪实，不影响其他扩展
- **电脑和手机都好用**：导航栏可以放在顶部（文字页签）或底部（图标），默认电脑放顶部、手机放底部
- 只支持单人聊天，不支持群聊

## 快速使用

装好后，打开一段单人聊天，一分钟内就能拿到导出文件。

1. 按下面的「安装方法」安装扩展，并在酒馆扩展设置里确认「纪实」已启用
2. 打开一段想要导出的单人聊天
3. 点输入框左边的魔法棒菜单，选择「纪实」
4. 在「导出预览」里确认效果，需要的话在「正则匹配」里点一下识别到的标签
5. 点右下角的「导出」，浏览器会自动下载文件

## 安装方法

1. 打开酒馆的扩展面板，选择安装扩展
2. 粘贴以下仓库地址完成安装

   ```text
   https://github.com/git-yafaya/ST-YaKit-chat
   ```
3. 刷新酒馆
4. 在扩展设置里确认「纪实」处于启用状态

## 使用说明

### 导出聊天

1. 在酒馆里打开一段单人聊天；如果是群聊，面板会提示「仅支持单人聊天」
2. 点输入框左边的魔法棒菜单，选择「纪实」，打开面板，默认进入「文本导出」页
3. 看「导出预览」：这里显示最近 2 条消息导出后的样子；某条内容被全部删掉时显示「（匹配后为空）」
4. 需要去掉或只留部分内容时，在「正则匹配」里：
   1. 选择「删除匹配」或「只保留匹配」
   2. 点「识别到的标签」里的按钮，自动加入对应规则；或者点「添加规则」自己填写
   3. 不需要的规则点右边的垃圾桶删除
5. 点「导出预览」右上角的「导出设置」，在左侧抽屉里调整：
   1. 楼层范围：默认导出全部楼层；关掉开关后填写起始、结束楼层，楼层从 0 开始计
   2. 消息类型：AI 回复、用户台词、系统提示至少选一种，否则无法导出
   3. 导出格式：选择 TXT、Markdown 或 EPUB，以及「带类别标注」或「仅正文」，下方示例会显示两者的区别
   4. 文件名：不填就用角色名加日期
6. 点「导出」，导出成功会提示「已导出 N 条消息」并自动下载；处理后没有任何内容时提示「没有可导出的内容」，不会下载空文件

面板会记住你的导出设置和规则，下次打开还在。

### 使用预设

预设保存导出页的消息类型、导出格式、带类别标注或仅正文、匹配方式和正则规则；楼层范围和文件名每次聊天不同，不放进预设。

1. 在导出页调好规则和设置，进入「预设」页签，点「存为新预设」
2. 名字框里已经填好当前角色卡的名字，可以改，点「保存」；存好后这套预设就是正在使用的
3. 以后在导出页底部的下拉框里选预设，规则和设置马上换过去，楼层范围和文件名保持不变；选「不使用预设」就不跟任何预设关联
4. 想改某套预设的内容：在导出页下拉框选中它，改好规则或设置，点「更新预设」
5. 在「预设」页签里，每套预设右边有四个按钮：重命名、复制、导出、删除；删除前会先确认，可以删光全部预设
6. 点「导入」选择别人分享的预设文件；名字重复时自动在后面加「(2)」「(3)」

有没保存的改动时切换预设，会先提醒改动会丢失。

### 备份和恢复

1. 进入「预设」页签，点「备份全部」，下载一个备份文件，里面有全部预设、正在用的预设、导出设置，以及主题、导航栏位置、主题切换方式
2. 换设备或重装后，点「从备份恢复」选择这个文件
3. 确认后会覆盖现有的全部预设和导出设置；文件不对时会提示「这不是纪实的备份文件」，现有内容不会被改动

### 换主题和导航栏位置

1. 点面板右上角的主题插画，每点一次换到下一个主题
2. 也可以进入「设置」页签，展开「主题」直接挑选；「切换方式」决定这里显示插画格子还是下拉框
3. 在「设置」里展开「导航栏位置」，可以选择「自动」「上方」「下方」

### 更新纪实

1. 进入「设置」页签，最上面一行是「插件更新」，行尾灰字写着当前版本和检查结果
2. 切到设置页时会自动检查一次（一分钟内不重复检查）；想马上再查一次，展开这一行点「检查更新」
3. 显示「有新版本」时，点「更新」
4. 更新成功会提示「纪实已更新，正在刷新网页」，稍等片刻网页自动刷新
5. 检查或更新失败时，按钮下方会写明原因，可以再点一次重试

## 设置说明

| 设置 | 可选值 | 默认 | 说明 |
| --- | --- | --- | --- |
| 主题 | 跟随ST、浅色、深色、冷杉与海盐、暮色无花果、橄榄岩与日光柠檬、暖橙晨曦、咩咩 | 冷杉与海盐 | 只改变纪实面板的样子，不影响酒馆本身 |
| 主题切换方式 | 自动、图标、下拉框 | 自动 | 电脑显示插画格子，手机显示下拉框 |
| 导航栏位置 | 自动、上方、下方 | 自动 | 电脑放上方，手机和平板放下方 |
| 楼层范围 | 全部楼层 / 指定起止楼层 | 全部楼层 | 楼层从 0 开始计 |
| 消息类型 | AI 回复、用户台词、系统提示 | 全部选中 | 隐藏的楼层和旁白（/sys）算系统提示 |
| 导出格式 | TXT、Markdown、EPUB；带类别标注、仅正文 | TXT、带类别标注 | EPUB 默认每章 2 条消息 |
| 文件名 | 任意文字 | 空 | 空时用角色名加日期 |

## 兼容性

已验证运行环境为 SillyTavern 1.18.0（本次开发和人工验收所用版本），其他版本暂未单独验证。
识别标签和正则匹配用到较新的浏览器正则能力，请使用近几年的 Chrome、Edge、Firefox 或 Safari。

## 常见问题

**Q：开了「导出全部楼层」，为什么导出的消息很少？**
A：被隐藏的楼层算作「系统提示」。如果只勾选了「AI 回复」或「用户台词」，隐藏过的楼层就不会被导出。在「导出设置」里把「系统提示」也勾上即可。

**Q：导入预设时提示「这不是纪实的预设文件」？**
A：只能导入纪实导出的预设文件（文件名以 .yakit-preset.json 结尾）。备份文件（.yakit-backup.json）请用「从备份恢复」。

**Q：切换预设后，楼层范围和文件名为什么没变？**
A：楼层范围和文件名每次聊天都不一样，所以不放进预设，切换预设时会保留你当前填的值。

**Q：插件更新显示「无法在线更新」？**
A：纪实不是通过仓库地址安装的（比如手动复制的文件夹），或者当前账号没有更新全局扩展的权限。请按「安装方法」用仓库地址重新安装，或让管理员更新。

**Q：检查或更新时提示「HTTP 500，请查看酒馆服务端日志」？**
A：酒馆服务器去仓库拉取时出了问题，常见原因有网络不通、用 SSH 地址安装但服务器不能使用 SSH、插件文件夹里有自己改过的文件。可以查看酒馆服务端日志找原因，或者用上面的 https 仓库地址重新安装。

**Q：菜单里找不到「纪实」？**
A：请到酒馆的扩展设置里确认「纪实」已经启用，然后刷新网页。
