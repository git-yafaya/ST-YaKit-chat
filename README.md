# 纪实

纪实是 YaKit 系列中的 SillyTavern 聊天记录扩展：先预览导出效果，点几下去掉思维链、状态栏这类不想要的内容（也可以让 AI 帮你写规则），再把当前聊天导出成 TXT、Markdown、EPUB 或酒馆聊天文件；还能让 AI 按你要的文风把聊天润色成连贯的正文再导出。

## 功能特性

- **导出预览**：面板最上方实时显示最近 2 条消息导出后的样子，改规则、改设置马上就能看到效果；填「看第几楼」可以直接看某一楼；点放大按钮可以按当前设置查看全部楼层，楼层多时往下滑分批加载
- **正则匹配**：三组规则同时生效——先按「只保留匹配」留下想要的部分，再按「替换」把指定文字换成别的，最后按「删除匹配」去掉剩下不想要的；某条规则写错了只会提示「这条规则无效，已忽略」，不影响其他规则
- **整理标签**：按你指定的楼层范围找出聊天里的标签（如 `<thinking>`、`<story_scene>`、`<details>`），按谁套在谁里面列出来，写明出现了多少次、出现在多少层；每个标签选「只要这段」「删掉整块」或「只删标签」，选了就写成规则、预览马上变，一个正则都不用自己写；没识别到的标签也能自己输入加进来
- **删掉的地方不粘连**：删掉整块的位置留一个空行，多余的空行会并成一个，正文不会接成一坨
- **AI 辅助写规则**：用大白话说想删掉或保留什么，AI 参考最近一条 AI 回复按现有规则清洗后的文字，生成最多 3 条规则并自己判断该进删除组还是保留组，先看加上后的效果再决定要不要加入；生成中关掉面板也会继续，完成后会提示
- **按楼层范围导出**：可以导出全部楼层，也可以指定起止楼层；填反了会自动对调，超出范围会自动收回到有效楼层，输入框里直接显示整理后的数字
- **按消息类型导出**：AI 回复、用户台词、系统提示可以任选几种；被隐藏的楼层按原来的类型算，也可以选择不导出隐藏的楼层
- **四种文件格式**：TXT、Markdown、EPUB 电子书，以及能直接导入回酒馆的「酒馆聊天」文件；前三种可以选择每段前面标出是谁说的（带类别标注），或者只保留正文
- **酒馆聊天文件**：把清洗后的正文存成酒馆能直接导入的聊天记录，只保留每层当前显示的那条回复，楼层范围和消息类型照样生效，其他信息原样保留
- **插画小说**：导出 EPUB 时打开「插画小说」，用柏宝绘、智绘姬生成过的图片会插在原来的位置；清洗规则不会把插图删掉，润色导出也能带图
- **自定义文件名**：不填时自动用角色名加日期命名
- **润色**：让 AI 按文风把聊天改写成通顺的正文；按楼层分批发送，可选重质量（每次 5 层）、均衡（10 层）、省次数（20 层）或自己填层数，开始前就显示大约要请求几次；先润色第 1 段给你看效果，满意再继续（**润色功能仍在测试中，可能还有问题**，建议先看第 1 段效果、留意额度，遇到问题欢迎反馈）
- **携带世界书**：润色时可以打开开关，把世界书里和这次原文有关的设定一起发给 AI，帮它理解人物和专名，不会写进结果
- **本次任务**：润色时可以额外写几句只针对这次的要求，也可以贴文风参考或人物、前情说明，按聊天保存，不改动文风预设
- **润色结果随时改**：结果按楼层显示，可以直接手动修改（不花次数），也可以只选几层楼重新润色；润色后字数明显变少的楼层会提醒你；回复被截断时自动从断掉的那层接着写
- **润色结果不丢**：结果按聊天保存在酒馆服务器上，刷新网页、关掉酒馆后打开同一个聊天还在；聊天后来又多了楼层，可以只润色新增的部分
- **导出预设**：把导出页的规则、消息类型和格式存成一套预设，在导出页下拉框里一键切换，润色时也能直接选用；可以重命名、复制、删除，也能导出成文件分享给别人或导入别人的预设
- **预设叠加**：可以同时选中几套预设一起用，规则按预设在列表里的先后拼起来，想固定下来点「存为新预设」
- **文风预设**：把想要的文字风格存成一套套文风，润色时选一套用；可以编辑、复制、删除、导出和导入
- **备份**：把导出预设、文风预设、三条提示词和纪实的界面设置存成一个文件，换设备或重装后一键恢复
- **API 管理**：可以沿用酒馆当前的 API，也可以给纪实单独添加 API 配置；正则助手、润色助手分别选择用哪个接口，并可以各自设置温度、Top P、Top K、频率惩罚、存在惩罚；超时时间和自动重试次数可以调整
- **自定义提示词**：破限词、正则助手、润色助手三类，每一类都能存好几条自己写的提示词，点一条就是用它；每类自带一条默认的，改坏了一键恢复默认
- **每个助手单独挑**：正则助手、润色助手可以各自指定用哪条破限词、哪条提示词，也可以跟着「自定义提示词」里正在用的那条走；破限词还能选「不使用」
- **九套主题**：默认「冷杉与海盐」，还可以选浅色、深色、暮色无花果、橄榄岩与日光柠檬、暖橙晨曦、咩咩（暗夜紫配赛博青）、霓虹夜城（黑底配荧光黄的赛博朋克风），或者「跟随ST」自动沿用你当前酒馆美化的颜色和字体
- **更新**：在设置里检查纪实有没有新版本，一键更新，更新完自动刷新网页；只更新纪实，不影响其他扩展；可以查看每个版本的更新公告，更新后第一次打开会自动弹出这一版的公告
- **报错记录**：纪实出过的错会记下来，反馈问题时一键复制
- **提醒小圆点**：出过报错或有新版本时，「设置」页签右上角点一个小圆点（报错是红色，新版本是主题色）；进设置展开对应那一行就消失
- **电脑和手机都好用**：导航栏可以放在顶部（文字页签）或底部（图标），默认电脑放顶部、手机放底部

## 快速使用

装好后，打开一段聊天，一分钟内就能拿到导出文件。

1. 按下面的「安装方法」安装扩展，并在酒馆扩展设置里确认「纪实」已启用
2. 打开一段想要导出的聊天
3. 点输入框左边的魔法棒菜单，选择「纪实」
4. 在「导出预览」里确认效果，需要的话点「整理标签」，给不想要的标签选「删掉整块」
5. 点右下角的「导出」，浏览器会自动下载文件

导出不需要任何配置；用「AI 辅助」和「润色」时，才需要酒馆里有能用的 API，或者在「API 管理」里添加一个。

## 安装方法

1. 打开酒馆的扩展面板，选择安装扩展
2. 粘贴以下仓库地址完成安装

   ```text
   https://github.com/git-yafaya/ST-YaKit-chat
   ```
3. 刷新酒馆
4. 在扩展设置里确认「纪实」处于启用状态

## 使用说明

### 导出聊天

1. 在酒馆里打开一段聊天；没有打开聊天时，面板会提示「先在酒馆里打开一个聊天」
2. 点输入框左边的魔法棒菜单，选择「纪实」，打开面板，默认进入「文本导出」页
3. 看「导出预览」：这里显示最近 2 条消息导出后的样子；某条内容被全部删掉时显示「（匹配后为空）」；想看某一楼，在标题行的「看第几楼」里填楼号；想看全部楼层，点标题右边的放大按钮
4. 需要去掉或只留部分内容时，在「正则匹配」里：
   1. 三组规则同时生效：「只保留匹配」先留下想要的部分，「替换」把指定文字换成别的，「删除匹配」去掉不想要的；上面的分段选择器只决定你在看哪一组，没在看的那两组照样生效
   2. 最省事的办法是点「整理标签」，在抽屉里给标签选怎么处理（见下面「整理标签」）
   3. 也可以点「添加规则」自己填写，或者点「AI 辅助」让 AI 帮忙写；替换规则一行两个框，左边填查找、右边填换成的文字
   4. 不需要的规则点右边的垃圾桶删除
5. 点「导出预览」右上角的「导出设置」，在左侧抽屉里调整：
   1. 楼层范围：默认导出全部楼层；关掉开关后填写起始、结束楼层，楼层从 0 开始计
   2. 消息类型：AI 回复、用户台词、系统提示至少选一种，否则无法导出；隐藏的楼层按原来的类型算
   3. 包含隐藏的楼层：默认打开；关掉后隐藏的楼层都不导出
   4. 导出格式：选择 TXT、Markdown、EPUB 或「酒馆聊天」，以及「带类别标注」或「仅正文」，下方示例会显示两者的区别；选「酒馆聊天」时不用选标注方式
   5. 文件名：不填就用角色名加日期
6. 点「导出」，导出成功会提示「已导出 N 条消息」并自动下载；处理后没有任何内容时提示「没有可导出的内容」，不会下载空文件

面板会记住你的导出设置和规则，下次打开还在。

### 整理标签

1. 在「正则匹配」里点「整理标签」，从底部上拉出抽屉，占半页；拖抽屉顶上的小横条可以调高调低，上面的导出预览随时能看到
2. 上面填识别的起止楼层，点「重新识别」；不填就是全部楼层，楼层多时要等一会儿
3. 中间按嵌套关系列出识别到的标签：缩进表示套在上一行里面，标签后面写着出现次数和出现在多少层；有下级的标签点左边的箭头可以收起
4. 每个标签在右边选怎么处理：
   1. 不处理：不生成规则
   2. 只要这段：只留下这个标签里面的正文
   3. 删掉整块：标签和里面的内容一起去掉，删掉的地方留一个空行
   4. 只删标签：去掉标签本身，里面的正文留着
5. 没识别到的标签，在下面的输入框里填标签名，点「加到列表」，一样能选怎么处理
6. 选了就直接写进规则，预览跟着变；底部写着已经写进了几条，看好了点「完成」

同一个标签名在列表里只出现一次，选的处理方式对整个聊天生效。每行显示的是规则里现在实际的处理方式：在规则列表里把标签生成的规则删掉或改掉，这一行就回到「不处理」。换一种处理方式时，只替换这个标签生成的规则，你自己写的和 AI 加的不动。叠加多套预设时只能看、不能改。

### 让 AI 帮忙写规则

1. 在「正则匹配」里点「AI 辅助」，右侧打开抽屉，顶部小字写着这次会用哪个接口和模型
2. 在「想删掉或保留什么」里用大白话描述，比如「去掉每条消息末尾的状态栏」
3. 点「生成规则」；AI 会参考当前聊天里最近一条没被隐藏的 AI 回复原文
4. 等待时可以关掉抽屉甚至整个面板，生成会继续；完成后会提示「规则已生成，打开 AI 辅助查看」
5. 看候选规则和下方「加上这些规则后的样子」，无效的规则会标出并忽略；不满意就点「重新生成」
6. 点「添加到规则」，有效且列表里还没有的规则会加进去

AI 辅助会消耗你所用 API 的额度或次数。回复格式不对时会按「参数」里的次数自动重试，每次重试也会消耗额度。

### 润色聊天

1. 打开要润色的聊天（只支持单人聊天），在纪实面板里进入「润色」页签；「润色结果」里先按段、按楼层显示这次要发给 AI 的原文，底部写着总字数和大约要请求几次
2. 点「润色结果」右上角的「润色设置」，在左侧抽屉里调整：
   1. 导出预设：消息类型、正则规则和导出格式都用这套预设，可以选「导出页当前设置」；「包含隐藏的楼层」跟着文本导出页走；润色导出只包含正文，不加类别标注
   2. 文风：选一套文风预设，或者「不使用文风」
   3. 本次任务（可以不填）：「补充要求」写只针对这次的要求；点「添加参考」贴参考材料，每条选「文风参考」（只学写法）或「上下文说明」（帮助理解人物和前情），最多 6 条；内容按聊天保存，下次开始、继续或重做时生效
   4. 携带世界书：打开后，每次请求会按这次要润色的楼层找出触发的世界书条目一起发送，只用来理解设定；会多消耗额度，默认关闭
   5. 楼层范围：默认润色全部楼层，也可以填起止楼层
   6. 每次发送：重质量每次 5 层楼、均衡 10 层楼、省次数 20 层楼，或者选「自定义」自己填层数；一次楼层越多请求次数越少，但越容易被截断
   7. 文件名：不填就用角色名加日期
3. 点「开始润色」：纪实先只润色第 1 段，完成后提示「第 1 段已润色好」，你可以对照「润色后」和「原文」看看效果
4. 满意就点「继续润色」，按顺序把剩下的段润色完；底部显示进度，遇到接口限速时会显示倒计时后自动继续，想暂停就点「停止」
5. 某段回复被截断时，纪实会保留已经写完整的楼层，自动从断掉的那层接着写；某段失败会写明原因，连续 2 段失败会自动停下
6. 看结果时可以：
   1. 点某一楼的修改按钮，直接改这楼的文字，保存不花次数
   2. 点楼号选中几层楼，再点底部「重新润色选中的楼层」，底部会写着大约要请求几次；选中的楼层里有手动改过的，会先确认再覆盖
   3. 某一段整体不满意，点这一段的「重新润色」，整段重来（会覆盖这一段的手动修改）
   4. 标着「字数明显变少」的楼层，可能被 AI 缩写了，可以重新润色或手动补上
7. 全部段都润色完成后，点底部「导出」下载文件；格式跟着所选导出预设，TXT 和 Markdown 按顺序接成正文，EPUB 每一段是一章；所选导出预设打开了「插画小说」时，生图标签不会发给 AI，导出 EPUB 时图片补回到原来附近的段落
8. 聊天后来又多了楼层时，「润色结果」上方会提示新增了几层，点「润色新增部分」只润色这些楼层

润色结果按聊天保存在酒馆服务器上，刷新网页、关掉酒馆后打开同一个聊天还在，关掉面板时润色也会继续。已经有结果时，润色设置里只能改文件名、文风和本次任务，要换导出预设、楼层范围或每次发送，先点润色设置底部左边的「重置」（本次任务的内容会一起清空）。如果之前的楼层在聊天里被改过或删掉，不能直接润色新增部分，需要重置后重新开始。

润色会消耗所用 API 的额度或次数，被截断后的续写、格式不对时的自动重试和重新润色都会再次请求。

润色功能仍在测试中，可能出现回复格式不对、被模型拒绝、字数变少或效果不理想等问题，建议先用第 1 段确认效果再继续，遇到问题欢迎反馈。

### 管理 API、助手和提示词

1. 进入「API 管理」页签，页面上有 API 配置、提示词、助手、参数四行，点一行在原地展开，行尾灰字写着当前状态
2. **API 配置**：第一行「主 API（跟随ST）」就是酒馆当前在用的 API；点「新建配置」可以单独添加一个，填名称、服务地址、密钥、模型名称，点「获取模型」可以从列表里选；「测试连接」会用填写的内容真实请求一次，会消耗额度或次数。点列表里的一行切换正在使用的配置
3. **助手**：正则助手、润色助手各有三个下拉框——用哪个接口、用哪条破限词、用哪条提示词；选「跟随使用中」就跟着正在用的那条走，破限词还可以选「不使用」
4. **采样参数**：每个助手下面可以填温度、Top P、Top K、频率惩罚、存在惩罚，输完离开输入框就保存；默认正则助手温度 0.8、润色助手温度 0.95，其他不设置；空着就是不设置，请求时不带这一项，由模型或服务自己决定；有些接口不支持某几项时会自动跳过；点每个助手右下角的「重置」，这个助手回到默认接口和采样参数
5. **参数**：超时时间默认 360 秒，自动重试默认 1 次，所有 AI 请求共用
6. **自定义提示词**：上面的分段选在看哪一类——破限词、正则助手、润色助手；每一类是一个列表，点某一行就是用它，行尾的按钮可以编辑、复制、删除
7. 点「新建提示词」写自己的：填名称和正文，保存后直接用起来；材料和输出格式由程序自动加在提示词后面，不用自己写
8. 每一类自带一条默认的提示词，可以改、可以复制，但不能删；编辑它时底部有「恢复默认」，把正文换回纪实自带的内容
9. 破限词的正文可以清空，空着时这次就不发破限词

纪实里切换 API 配置、填写采样参数都不会改动酒馆本身的 API 设置和预设。

### 使用导出预设

导出预设保存导出页的消息类型、导出格式、带类别标注或仅正文、三组正则规则和标签的处理方式；楼层范围、文件名和「包含隐藏的楼层」不放进预设。

1. 在导出页调好规则和设置，进入「预设」页签，确认右上角选的是「导出预设」，点「存为新预设」
2. 名字框里已经填好当前角色卡的名字，可以改，点「保存」；存好后这套预设就是正在使用的
3. 以后在导出页底部的下拉框里选预设，规则和设置马上换过去，楼层范围和文件名保持不变；选「不使用预设」就不跟任何预设关联
4. 想改某套预设的内容：在导出页下拉框选中它，改好规则或设置，点「更新预设」
5. 每套预设右边有四个按钮：重命名、复制、导出、删除；删除前会先确认，可以删光全部预设
6. 点「导入」选择别人分享的预设文件；名字重复时自动在后面加「(2)」「(3)」

7. 想同时用几套预设，在导出页下拉框里多选几项，或者在预设页点亮几行：规则按预设在列表里的先后拼起来，重复的只留一条；消息类型、导出格式这些只能有一个答案的设置，以及同一个标签的处理方式，由靠后的一套说了算
8. 叠加时规则是拼出来的，改不了也存不回某一套；想在这个基础上接着改，点底部「存为新预设」存成新的一套，或者先只用一套

有没保存的改动时换预设，会先提醒改动会丢失。润色时选用的导出预设被删掉后，会改用导出页当前设置，已有的润色结果不受影响。

### 使用文风预设

1. 进入「预设」页签，点右上角的「文风预设」
2. 点「新建文风」，填名称和文风要求（比如「句子短一些，多写动作和神态」），点「保存」；不知道怎么写时，点「插入模板」在正文末尾加上文风目标、适用范围、视角、句式节奏、对白与心理描写、表达取舍、对照范例几个小标题
3. 点列表里的一行，就把它设为润色时使用的文风；也可以在润色设置的「文风」里选，两边是同一个选择；选「不使用文风」就不加文风要求
4. 每套文风右边有四个按钮：编辑、复制、导出、删除；删掉正在用的文风后，润色变为不使用文风
5. 点「导入」选择别人分享的文风文件（文件名以 .yakit-style.json 结尾）

润色中途换文风，已经润色好的内容不变，之后的请求按新文风。

### 备份和恢复

1. 进入「预设」页签，点最上面的「备份全部」，下载一个备份文件，里面有全部导出预设、正在用的导出预设、导出设置、全部文风预设和正在用的文风、三类自定义提示词（连同你自己写的那些），以及主题、导航栏位置、主题切换方式
2. API 配置和密钥、助手选的接口和采样参数、超时和重试设置、润色设置和润色结果都不在备份里
3. 换设备或重装后，点「从备份恢复」选择这个文件；确认后会覆盖备份里有的内容，旧版本的备份里没有文风和提示词时，本机的这两项保持不变；文件不对时会提示，现有内容不会被改动

### 换主题和导航栏位置

1. 点面板右上角的主题插画，每点一次换到下一个主题
2. 也可以进入「设置」页签，展开「主题」直接挑选；「切换方式」决定这里显示插画格子还是下拉框
3. 在「设置」里展开「导航栏位置」，可以选择「自动」「上方」「下方」

### 更新纪实

1. 进入「设置」页签，最上面一行是「更新」，行尾灰字写着当前版本和检查结果
2. 切到设置页时会自动检查一次（一分钟内不重复检查）；想马上再查一次，展开这一行点「检查更新」
3. 想知道每个版本改了什么，点「检查更新」上面的「更新公告」；有还没安装的新版本时，它的公告排在最上面，标着「还没更新」
4. 显示「有新版本」时，点「更新」
5. 更新成功会提示「纪实已更新，正在刷新网页」，稍等片刻网页自动刷新；更新后第一次打开纪实会自动弹出这一版的公告
6. 检查或更新失败时，按钮下方会写明原因，可以再点一次重试

### 看提醒小圆点

1. 「设置」页签右上角有小圆点时，表示这里有需要你看的东西：红色是纪实出过报错，主题色是有新版本
2. 两样都有时显示红色
3. 进「设置」页展开「报错记录」，红点消失；展开「更新」那一行，新版本的点消失；两项各自独立
4. 之后再出新的报错或再查到新版本时，小圆点会重新出现

### 反馈问题

1. 进入「设置」页签，展开「报错记录」，这里按时间列出纪实最近出过的错（最多 50 条）
2. 点「复制全部」，把内容连同问题描述一起发给作者
3. 点「清空」可以删掉全部记录

## 常见问题

**Q：开了「导出全部楼层」，为什么导出的消息很少？**
A：先看「导出设置」里的消息类型是不是只勾了一部分，再看「包含隐藏的楼层」是不是关掉了。隐藏的楼层按原来的类型算，比如隐藏的 AI 回复要勾「AI 回复」才会导出。

**Q：AI 辅助提示「没有拿到规则，可能被模型拒绝了」？**
A：模型没有按要求回复。可以换个说法再试，或者在「API 管理」里检查通用破限词是不是被清空了，也可以给正则助手换一个接口。

**Q：润色一个很长的聊天要请求多少次？**
A：看润色页底部的「约 N 次请求」，大致等于分出来的段数。想少请求几次，在润色设置里把「每次发送」换成省次数或自定义更多层；被截断后的续写、自动重试和重新润色会再多请求几次。

**Q：润色完成了，为什么「导出」点不了？**
A：必须每一段都润色成功才能导出。找到标着「失败」或还没润色的段，点「继续润色」或这一段的「重新润色」。

**Q：刷新网页后润色结果还在吗？**
A：在。结果按聊天保存在酒馆服务器上，打开同一个聊天就能看到；正在润色时刷新，会停在刷新前已经保存的地方，点「继续润色」接着做。聊天文件或角色卡改了名字时，会当成另一个聊天，找不到之前的结果。

**Q：为什么不能「润色新增部分」，提示要清空结果？**
A：之前已经润色过的楼层在聊天里被改过、删掉或换了回复，接着追加会对不上楼层。已有结果还能继续修改和导出；想把新楼层也润色，需要在润色设置里点「重置」后重新开始。

**Q：保存 API 配置时提示「服务地址里有全角符号或特殊空格，请改成半角」？**
A：地址里混进了中文输入法打出的符号（比如「？」「：」「／」）或特殊空格，把它们改成英文半角符号即可。

**Q：关掉 AI 辅助或润色页后还会扣额度吗？**
A：会。关掉抽屉或面板时生成会继续，完成后提示你查看结果；想停下来请点「停止」。

**Q：导入预设时提示「这不是纪实的预设文件」？**
A：导出预设只能导入纪实导出的预设文件（文件名以 .yakit-preset.json 结尾），文风预设用 .yakit-style.json 文件。备份文件（.yakit-backup.json）请用「从备份恢复」。

**Q：切换预设后，楼层范围和文件名为什么没变？**
A：楼层范围和文件名每次聊天都不一样，所以不放进预设，切换预设时会保留你当前填的值。

**Q：更新显示「无法在线更新」？**
A：纪实不是通过仓库地址安装的（比如手动复制的文件夹），或者当前账号没有更新全局扩展的权限。请按「安装方法」用仓库地址重新安装，或让管理员更新。

**Q：检查更新或读取更新公告时提示「HTTP 500，请查看酒馆服务端日志」？**
A：酒馆服务器去仓库拉取时出了问题，常见原因有网络不通、用 SSH 地址安装但服务器不能使用 SSH、插件文件夹里有自己改过的文件。可以查看酒馆服务端日志找原因，或者用上面的 https 仓库地址重新安装。

**Q：菜单里找不到「纪实」？**
A：请到酒馆的扩展设置里确认「纪实」已经启用，然后刷新网页。
